# 📖💻 Biblie + Tehnologie

Materialele publice ale cursului **„Credință & Tehnologie”** pentru preadolescenți (clasele 5–8):
o seară la două săptămâni, în care o poveste sau un principiu biblic se întâlnește cu un concept
din tehnologie. Învățăm să discernem, să evaluăm și să folosim tehnologia într-un mod sănătos,
care Îl onorează pe Dumnezeu.

🌐 **Site:** [nmatei.github.io/bible-tech](https://nmatei.github.io/bible-tech/)

## Lecții

| # | Lecția | Materiale |
|---|---|---|
| 1 | **Cum vorbesc calculatoarele?** — mesaje prin fire și becuri (numere binare), periferice, internet și verificarea surselor. _Matei 5:37_ | [▶ Prezentarea](https://nmatei.github.io/bible-tech/lectii/lectia-1/) |

## Aplicații

- [📄 **Alfabetul pe fire**](https://nmatei.github.io/bible-tech/lectii/alfabet-binar/) — fișa de cod
  pentru jocul cu becuri: alfabetul românesc pe 5 fire (1–8 fire configurabil), animație pe
  fiecare literă, fereastră cu becurile pentru TV și foaie de decodare de printat.

## Rulare locală

```bash
npm install
npm start      # servește docs/ pe http://localhost:3000
```

> `docs/` e generat automat dintr-un repo separat (build minificat) și publicat prin GitHub Pages.
> Nu edita fișierele de aici de mână: se suprascriu la următoarea publicare.
