# 📖💻 Biblie + Tehnologie

Materialele publice ale cursului **„Credință & Tehnologie”** pentru preadolescenți: 
în care o poveste sau un principiu biblic se întâlnește cu un concept
din tehnologie. **Învățăm să discernem**, să evaluăm și să folosim tehnologia într-un mod sănătos,
care **Îl onorează pe Dumnezeu**.

🌐 **Site:** [nmatei.github.io/bible-tech](https://nmatei.github.io/bible-tech/)

## Lecții

| # | Lecția | Materiale |
|---|---|---|
| 1 | **Cum vorbesc calculatoarele?** — mesaje prin fire și becuri (numere binare), curentul prin circuit, jocul cu firele. _Matei 5:37_ | [▶ Prezentarea](https://nmatei.github.io/bible-tech/lectii/lectia-1/) |
| 2 | **Cum circulă informația?** — periferice, tastatura pe dinăuntru, internetul și verificarea surselor. _1 Tesaloniceni 5:21_ | [▶ Prezentarea](https://nmatei.github.io/bible-tech/lectii/lectia-2/) |
| 3 | **Mesajul de pe zid** — Daniel 5, același alfabet pe o placă ESP32, Morse pe un bec și jocul „ultimul decodor”. _Amos 3:7_ | [▶ Prezentarea](https://nmatei.github.io/bible-tech/lectii/lectia-3/) |
| 4 | **Scratch: becul care se aprinde** _(în lucru)_ — un LED se aprinde doar când atinge corect bornele + și −; reguli „dacă … atunci”. _Ioan 15:5_ | [▶ Prezentarea](https://nmatei.github.io/bible-tech/lectii/lectia-4/) |

## Aplicații

- [📄 **Alfabetul pe fire**](https://nmatei.github.io/bible-tech/lectii/alfabet-binar/) — fișa de cod
  pentru jocul cu becuri: alfabetul românesc pe 5 fire (1–8 fire configurabil), animație pe
  fiecare literă, fereastră cu becurile pentru TV, redare automată și foaie de decodare de printat.
- [📡 **Morse pe un bec**](https://nmatei.github.io/bible-tech/lectii/alfabet-binar/morse) — același mesaj
  în codul Morse, pe un singur bec, cu bip opțional; tabelul Morse și foaia de decodare, de printat.
- [📜 **Versete pe fire**](https://nmatei.github.io/bible-tech/lectii/alfabet-binar/versete-olimpiada-biblica-2027) —
  versetele de memorat pentru Olimpiada Biblică 2027, pregătite pentru 5 fire, în perechi cu același
  număr de simboluri pentru cele două echipe; se printează pe A4, câte o jumătate de foaie pe echipă.

## Rulare locală

```bash
npm install
npm start      # servește docs/ pe http://localhost:3000
```

> `docs/` e generat automat dintr-un repo separat (build minificat) și publicat prin GitHub Pages.
> Nu edita fișierele de aici de mână: se suprascriu la următoarea publicare.
